# Make the AI Judge Feel Proud — a family scene

A `main.ts` (Node 22 stdlib only) that writes one original, warm and funny
family scene — one line, under 280 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` for the
[make.fun bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2).

## The scene

> Forty years in, Mom still cuts the crusts off Dad's sandwiches — and Dad still pretends not to notice, then eats the crusts off her plate when she isn't looking.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
